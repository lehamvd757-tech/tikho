# ТИХО — лендинг

Антистресс-набор для мужчин. Выпуск 01: Контроль.

## Деплой на Vercel

### Вариант 1 — Drag & Drop (быстрый)
1. Зайди на [vercel.com](https://vercel.com)
2. Нажми **Add New → Project**
3. Выбери **"Deploy from your computer"** → перетащи папку `tikho`
4. Готово — Vercel выдаст URL

### Вариант 2 — через GitHub
1. Создай репозиторий на GitHub, загрузи папку
2. В Vercel: **Add New → Project → Import Git Repository**
3. Выбери репо → **Deploy**

## Перед деплоем — обязательно замени

В файле `index.html` найди и замени:

| Заглушка | Что поставить |
|---|---|
| `70000000000` | Твой номер в формате `79991234567` |
| `https://max.ru/` | Ссылка на твой профиль в Max |

Поиск по файлу: `Ctrl+H` → `70000000000`
